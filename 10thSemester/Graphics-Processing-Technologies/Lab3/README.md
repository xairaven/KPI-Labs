### Завдання:

Дослiдити методи паралельного навчання моделей з використанням кiлькох графiчних процесорiв 
(multi-GPU), зокрема пiдходи data parallelism та model parallelism, i виконати експериментальне 
порiвняння їх обчислювальної ефективностi з одно-GPU режимом.

Використати датасет CIFAR-10 для побудови та навчання базової згорткової нейронної мережi у одно-GPU
режимi з фiксацiєю ключових метрик, зокрема часу навчання, значення функцiї втрат i точностi класифiкацiї.
Пiсля цього слiд реалiзувати розподiлене навчання тiєї ж моделi з використанням пiдходу data parallelism
(розподiл батчiв мiж кiлькома GPU з подальшою агрегацiєю градiєнтiв), а також пiдходу model parallelism
(розподiл шарiв або частин моделi мiж кiлькома GPU), i виконати повторне навчання з аналогiчною фiксацiєю
метрик.

Отриманi результати необхiдно порiвняти, проаналiзувавши вплив кожного пiдходу на час навчання, точнiсть
моделi та ефективнiсть використання обчислювальних ресурсiв, включаючи оцiнку прискорення (speedup),
ефективностi масштабування та накладних витрат на мiжпроцесорну взаємодiю. На основi проведених експериментiв 
потрiбно сформулювати висновки щодо переваг i обмежень data parallelism та model parallelism,
визначити сценарiї їх доцiльного застосування, а також пояснити причини можливих втрат продуктивностi 
або вiдсутностi очiкуваного прискорення. Результати виконання роботи необхiдно оформити у виглядi
Jupyter Notebook, який мiстить програмну реалiзацiю, експериментальнi дослiдження та отриманi результати, 
а також пiдготувати аналiтичний звiт з обґрунтованими висновками щодо ефективностi використаних пiдходiв.

Speedup = T1 / Tp, де T1 — час виконання (навчання) на одному GPU, Tp — час виконання на P GPU.

Для практичної роботи рекомендується використовувати платформу Kaggle. У налаштуваннях середовища
(Settings -> Accelerator) необхiдно обрати режим GPU T4 × 2 для забезпечення можливостi проведення
експериментiв iз використанням кiлькох GPU.
