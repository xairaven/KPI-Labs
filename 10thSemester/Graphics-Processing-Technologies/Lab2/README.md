### Завдання:

У [прикладi](https://github.com/lintenn/cudaAddVectors-explicit-vs-unified-memory) подано реалiзованi два варiанти ядра для додавання векторiв (`AddVectorsInto`). 
В одному з них використано унiфiковану пам’ять (`cudaMallocManaged`, `cudaMemPrefetchAsync` ...), 
а в iншому – явно видiляється пам’ять для векторiв на хостi (CPU) та GPU (`malloc`, `cudaMalloc`) 
i виконано передачу вручну за допомогою `cudaMemcpy`.

Оптимiзуйте додавання елементiв векторiв, використовуючи кешування в спiльнiй пам’ятi (`shared memory`).
Порiвняйте продуктивнiсть для трьох варiантiв за допомогою NVIDIA Visual Profiler, подайте власнi 
спостереження та висновки. Результати порiвняльного аналiзу оформiть у виглядi звiту. 
У звiтi також подайте лiстинги програм та iнформацiю про апаратне забезпечення на якому виконувались експерименти.
